怎么让几个人都收到

推荐 PushPlus —— 关注一个公众号就能收，不用装 App 也不用建群
  1. 微信搜公众号「pushplus 推送加」，关注后发送「token」，它会回一串 token 给你
  2. 在它的个人中心完成实名认证，不实名接口一律返回 905，发不出去
  3. 每人一个 token，逗号隔开填到下面「PushPlus Token」，点「发送测试推送」
备选 企业微信群机器人 —— 收消息的人都要装企业微信
  1. 注册一个企业微信（选「团队」，个人也能注册），把家人手机号加进通讯录
  2. 电脑端进群 → 右上角「···」→ 群机器人 → 添加 → 复制 Webhook
  3. 填到下面「企业微信 Webhook」，打开「群内 @所有人」

三条通道按省事程度排：PushPlus 最轻，关注公众号即可，免费 200 条/天； 企业微信群机器人要多装一个 App，且只有内部群能加； Server 酱什么都不用装，但免费只有每天 5 条，日常提醒不够用。

数据管理

本项目代码中不含任何真实用药数据。此处写入的内容只存在 data/app.db 这个 SQLite 文件里， 备份或迁移时复制该文件即可。

导入用药计划

每行一条。列顺序 时间, 药品/项目, 剂量, 方式, 备注, 启用, 星期, 推送，后五列可留空。 星期列可写 每天、工作日、周末、 周一、周三，留空视为每天；若只用数字（如 1,3,5）需用英文引号包住整格。 推送列写 否 表示这条不发微信，留空视为发。 支持从 Excel 直接复制（制表符分隔），也可导入本页导出的 plans.csv。 首行表头会自动跳过，重复的「时间+药品」不会重复导入。
